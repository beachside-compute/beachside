Add opt-in sandbox credential grants and a trusted-host client for the self-hosted Beachside credential broker. Git, GitHub CLI, and model clients can use a short-lived sandbox token through the broker. Manage named integrations and encrypted credentials at runtime with a separate admin client and the `beachside-broker` CLI, explicitly authorize integrations for issuance, and select distinct GitHub identities for separate sandbox grants.
