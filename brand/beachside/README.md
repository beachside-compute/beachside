# Beachside product branding

`social-preview-1280x640.png` is an upload-ready 1280 × 640 repository social-preview image for the beachside.run product and docs repositories. The companion SVG is the editable master.

It uses the striped sunset from `apps/docs/src/components/Logo.astro`, the docs palette, and Unbounded at weight 800 with the same tracking and skew as the docs wordmark. Lettering is outlined, so no fonts or external resources are needed. The navy background is opaque.

This is the Beachside product identity; parent-company assets are in `../beachside-compute/`.

`src/beta-social-1200x630.html` is the source for the 1200 × 630 X / Open Graph link preview of the 1.0 beta page, now at https://beachsidecompute.com/beta/ (beachside.run/beta redirects there). It is published as `apps/docs/public/brand/beachside/beta-social-1200x630.png`, kept so earlier shares still show their preview, and copied to the `beachside-landing` repository. Render it at a 1200 × 630 viewport after its fonts load.
